# 鉴权绕过 — 注解失效

> **类型 ID**: `AP-AUTH-ANNOTATION-FAIL`
> **轨道**: FWD-B
> **业务域**: 9 类必查之一

## 一、定义

`@PreAuthorize` 等鉴权注解存在但实际不生效（启用配置缺失、表达式错、AOP 织入失败等）。

## 二、典型场景

### 2.1 启用配置缺失
```java
// ❌ 没启用方法级安全
@Configuration
@EnableWebSecurity  // 没加 @EnableGlobalMethodSecurity(prePostEnabled = true)
public class SecurityConfig { ... }
```

### 2.2 表达式错误
```java
// ❌ 表达式写错
@PreAuthorize("hasRole('ADMIN') || hasRole('USER')")  // 期望 admin，但包含 user
@PreAuthorize("hasRole(ADMIN)")  // 缺引号
@PreAuthorize("#userId == userId")  // 表达式语法错
```

### 2.3 AOP 失效
```java
// ❌ 同类内部调用，绕过代理
@Service
public class UserService {
    public void outer() {
        inner();  // 内部调用，不走代理，@PreAuthorize 失效
    }
    
    @PreAuthorize("hasRole('ADMIN')")
    public void inner() { ... }
}
```

### 2.4 注解在接口 vs 实现
```java
// 注解在接口方法上，但 CGLIB 代理用类继承方式
public interface UserService {
    @PreAuthorize("hasRole('ADMIN')")
    void delete();  // 接口上的注解可能不生效
}

@Service
public class UserServiceImpl implements UserService {
    public void delete() { ... }  // JDK 动态代理时，注解在接口生效；CGLIB 时代理类需要重复注解
}
```

## 三、检测启发式

### 3.1 关键信号
- `@PreAuthorize` 存在但 `SecurityConfig` 没 `@EnableGlobalMethodSecurity`
- 表达式含 `||`（可能错判）
- 内部调用（`this.method()`）
- 注解在接口，实现类无注解

### 3.2 SQLite 特征
```sql
-- 找 @PreAuthorize 但没 @EnableGlobalMethodSecurity 的项目
SELECT m.fqn FROM method m
WHERE m.annotation LIKE '%PreAuthorize%'
  AND m.class NOT IN (
    SELECT fqn FROM class WHERE annotation LIKE '%EnableGlobalMethodSecurity%'
  )

-- 找同类内部调用
SELECT m.fqn FROM method m
WHERE m.body LIKE 'this.%(%'  -- this.method() 调用
```

## 四、缺失规则

- 启用方法级安全是**前置**条件
- 内部调用走代理（AopContext.currentProxy()）
- 注解在接口时，强制要求实现类也加
