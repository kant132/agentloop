# 任意文件下载

> **类型 ID**: `AP-FILE-DOWNLOAD`
> **轨道**: FWD-C
> **业务域**: 9 类必查之一

## 一、定义

文件下载接口接收用户输入的路径，未做边界检查，攻击者可下载任意文件（如 `/etc/passwd`、源码、配置）。

## 二、典型场景

```java
// ❌ 路径未规范化
@GetMapping("/download")
public void download(@RequestParam String path, HttpServletResponse resp) throws IOException {
    File file = new File("/data/" + path);  // path=../../etc/passwd
    Files.copy(file.toPath(), resp.getOutputStream());
}
```

## 三、检测启发式

```yaml
pattern: |
  $RESP.setHeader(...)
  Files.copy(new File($PATH + $VAR).toPath(), $RESP.getOutputStream())
```

## 四、缺失规则

- 路径必须在白名单目录内
- 文件名必须不含 `..`
- 文件大小限制
- 不可下载 `application/octet-stream` 之外的敏感文件
