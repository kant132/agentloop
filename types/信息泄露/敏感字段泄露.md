# 敏感字段泄露

> **类型 ID**: `AP-INFO-SENSITIVE`
> **轨道**: FWD-INFO
> **业务域**: 9 类必查之一

## 一、定义

API 响应包含未脱敏的敏感字段（密码 hash、身份证、银行卡、手机号等）。

## 二、典型场景

```java
// ❌ 返回 User 实体包含密码 hash
@GetMapping("/users/{id}")
public User getUser(@PathVariable Long id) {
    return userService.findById(id);
}
// User 实体有 passwordHash 字段，默认 Jackson 序列化输出

// ❌ 日志打印完整对象
log.info("User: {}", user);  // 包含 passwordHash
```

## 三、检测启发式

### 3.1 关键信号
- 返回实体含 `password` / `passwordHash` / `idCard` / `bankCard` / `phone` 等字段
- **缺失**：`@JsonIgnore` / DTO 转换 / 字段过滤

### 3.2 SQLite 特征
```sql
-- 找含敏感字段的实体类
SELECT c.fqn, c.fields FROM class c
WHERE c.fields LIKE '%password%'
   OR c.fields LIKE '%idCard%'
   OR c.fields LIKE '%bankCard%'
```

## 四、消毒器

| 消毒器 | 检测特征 |
|--------|---------|
| **`@JsonIgnore`** | 字段上标注 |
| **DTO 转换** | 显式 `UserDTO` 包含安全字段 |
| **脱敏注解** | `@JsonSerialize(using = SensitiveSerializer.class)` |
| **字段过滤** | `MappingJacksonValue` 动态过滤 |

## 五、误报模式

- 字段已有 `@JsonIgnore`
- 字段在 DTO 中被过滤
- 仅返回部分字段（白名单接口）
