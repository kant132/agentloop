# 日志泄露

> **类型 ID**: `AP-INFO-LOG`
> **轨道**: FWD-INFO
> **业务域**: 9 类必查之一

## 一、定义

日志输出含敏感信息（密码、token、身份证、银行卡），攻击者拿到日志即可获取敏感数据。

## 二、典型场景

```java
// ❌ 打印密码
log.info("Login attempt: user={}, password={}", username, password);

// ❌ 打印 token
log.info("Request headers: {}", request.getHeaders());

// ❌ 打印身份证
log.info("User info: {}", user);  // user 含 idCard
```

## 三、检测启发式

### 3.1 AST 模式
```yaml
pattern: log.$LEVEL($$$ARGS)  # 任意日志输出
# 配合：参数含 password/token/idCard
```

### 3.2 SQLite 特征
```sql
SELECT m.fqn FROM method m
WHERE m.body LIKE '%log.info%password%'
   OR m.body LIKE '%log.info%token%'
   OR m.body LIKE '%log.info%idCard%'
   OR m.body LIKE '%log.info%bankCard%'
   OR m.body LIKE '%logger.info%secret%'
```

## 四、缺失规则

- 日志输出禁止含：password / token / secret / idCard / bankCard
- 应使用脱敏：`log.info("user={}, password=***", username)`
- 应使用结构化日志 + 字段级脱敏注解
