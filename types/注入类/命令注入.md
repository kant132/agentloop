# 命令注入（RCE）

> **类型 ID**: `AP-INJ-RCE`
> **轨道**: FWD-A
> **业务域**: 9 类必查之一（最高危）

## 一、定义

用户输入未经过滤，被拼接到系统命令中执行。攻击者可在服务器上执行任意命令。

## 二、典型场景

### 2.1 Runtime.exec
```java
// ❌ 字符串拼接
Runtime.getRuntime().exec("ping " + userInput);
// 即使 exec(String[]) 形式，命令与参数都在数组中仍可注入
// exec(["ping", "-c", "1", userInput])  →  userInput 是 hostname 仍可控
```

### 2.2 ProcessBuilder
```java
// ❌ 列表拼接
ProcessBuilder pb = new ProcessBuilder("sh", "-c", "echo " + userInput);
```

### 2.3 ScriptEngine
```java
// ❌ 表达式注入
ScriptEngine engine = new ScriptEngineManager().getEngineByName("js");
engine.eval("var x = " + userInput);
```

### 2.4 Native 库调用
```java
// JNI / Runtime.load / native exec
```

## 三、检测启发式

### 3.1 AST 模式
```yaml
pattern: Runtime.getRuntime().exec($CMD + $VAR)
pattern: new ProcessBuilder($CMD + $VAR)
pattern: $ENGINE.eval($EXPR + $VAR)
pattern: new ScriptEngineManager().getEngineByName($NAME).eval($VAR)
```

### 3.2 SQLite 特征
```sql
SELECT m.fqn FROM method m
WHERE m.body LIKE '%Runtime.getRuntime().exec%'
   OR m.body LIKE '%ProcessBuilder%'
   OR m.body LIKE '%ScriptEngine%eval%'
   OR m.body LIKE '%GroovyShell%evaluate%'
```

## 四、消毒器

| 消毒器 | 检测特征 | 局限 |
|--------|---------|------|
| **白名单命令** | 命令必须在 `ALLOWED_COMMANDS` 集合内 | 仅对命令名限制 |
| **参数化 exec** | 用 `exec(String[])` + 数组传参 | 仅对参数分隔有效 |
| **路径规范化** | `FilenameUtils.getName` | 仅对路径 |
| **完全禁用** | `SecurityManager.checkExec` | JVM 1.8+ 已废弃 |

## 五、误报模式

- 命令完全硬编码
- exec 的参数全部来自白名单
- 调用在 try-catch 内的 sandbox

## 六、业务影响

**最高** — 直接 RCE
- 读取任意文件
- 反弹 shell
- 内网横向
- 持久化后门
