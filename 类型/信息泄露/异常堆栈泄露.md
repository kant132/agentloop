# 异常堆栈泄露

> **类型 ID**: `AP-INFO-STACK`
> **轨道**: FWD-INFO（无 sink 漏洞）
> **业务域**: 9 类必查之一

## 一、定义

生产环境异常处理返回完整堆栈、错误信息、SQL 语句等敏感信息，攻击者可借此了解系统结构。

## 二、典型场景

```java
// ❌ 直接返回异常
@ExceptionHandler(Exception.class)
public ResponseEntity<?> handle(Exception e) {
    return ResponseEntity.status(500).body(e);  // 完整堆栈返回
}

// ❌ e.printStackTrace() 输出到 response
StringWriter sw = new StringWriter();
e.printStackTrace(new PrintWriter(sw));
response.getWriter().write(sw.toString());
```

## 三、检测启发式

### 3.1 AST 模式
```yaml
pattern: |
  @ExceptionHandler
  public $RET $METHOD($E) { return ... $E ... }
```

### 3.2 SQLite 特征
```sql
SELECT m.fqn FROM method m
WHERE m.annotation LIKE '%ExceptionHandler%'
  AND (m.body LIKE '%e.getMessage()%' OR m.body LIKE '%e.getStackTrace()%' OR m.body LIKE '%printStackTrace%')
```

## 四、缺失规则

- 全局异常处理应只返回错误码 + 友好提示
- 详细日志写到服务端，**不**返回客户端
- 生产环境禁用 `server.error.include-stacktrace=always`
- Spring Boot 配置 `server.error.include-stacktrace=never`
