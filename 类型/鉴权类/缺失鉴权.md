# 缺失鉴权

> **类型 ID**: `AP-AUTH-MISSING`
> **轨道**: FWD-B（无明确 sink，**缺**关键校验）
> **业务域**: 9 类必查之一

## 一、定义

端点没有任何鉴权机制（Filter、Interceptor、注解），可被未认证用户直接访问。

## 二、典型场景

```java
// ❌ Controller 方法无任何鉴权
@RestController
public class AdminController {
    @GetMapping("/admin/users")
    public List<User> list() {  // 无 @PreAuthorize
        return userService.findAll();
    }
}

// ❌ 自定义注解未生效（注解处理器缺失）
@RestController
public class OrderController {
    @GetMapping("/orders")
    @RequiresLogin  // 自定义，但项目没有 HandlerInterceptor
    public List<Order> list() { ... }
}
```

## 三、检测启发式

### 3.1 关键信号
- Controller / Servlet 方法
- 路径敏感（`/admin/`、`/api/`、`/internal/`）
- **缺失**：`@PreAuthorize` / `@Secured` / `@RequiresPermissions` / Filter 覆盖
- **缺失**：方法在 Filter 链覆盖范围外

### 3.2 AST 模式
```yaml
pattern: |
  public $RET $METHOD($$$PARAMS) { $$$BODY }
# 配合：所在类 @RestController + 方法无 @PreAuthorize
```

### 3.3 SQLite 特征
```sql
SELECT m.fqn, m.class, m.file, m.line
FROM method m
JOIN class cls ON cls.fqn = m.class
WHERE cls.annotation LIKE '%Controller%'
  AND m.annotation NOT LIKE '%PreAuthorize%'
  AND m.annotation NOT LIKE '%Secured%'
  AND m.annotation NOT LIKE '%RolesAllowed%'
  AND m.annotation NOT LIKE '%RequiresPermissions%'
  AND (m.path LIKE '/api/%' OR m.path LIKE '/admin/%')
```

## 四、缺失规则

| 端点分类 | 必需鉴权 |
|----------|---------|
| `/admin/**` | admin 角色 + 登录 |
| `/api/**` 增删改 | 登录 |
| `/api/**` 读 | 登录（除非白名单） |
| `/internal/**` | 内网 IP 或 admin |
| `/public/**` | 无（白名单） |

## 五、误报模式

- 路径在 `permitAll` 白名单
- 内部网络 IP 限制（但 FWD-B 需结合环境信息判定）
- 单点登录 / SSO 已通过 Filter
- 健康检查端点 `/health` / `/actuator/health`
