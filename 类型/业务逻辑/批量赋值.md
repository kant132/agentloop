# 批量赋值（Mass Assignment）

> **类型 ID**: `AP-BIZ-MASS-ASSIGN`
> **轨道**: FWD-C
> **业务域**: 9 类必查之一

## 一、定义

框架自动将请求体绑定到对象所有字段。攻击者可传入未预期的字段（如 `role`、`isAdmin`、`balance`），覆盖业务字段。

## 二、典型场景

```java
// ❌ Spring 直接绑定
@PostMapping("/users")
public User createUser(@RequestBody User user) {
    return userService.save(user);  // user.role, user.balance 等都被绑定
}

// ❌ JPA / MyBatis-Plus save
@PostMapping("/users")
public User createUser(@RequestBody User user) {
    return userRepository.save(user);  // 同上
}
```

## 三、检测启发式

### 3.1 关键信号
- `@RequestBody` + 直接 `save` / `update` / `insert`
- 实体类有 `role` / `isAdmin` / `balance` / `status` 等敏感字段
- **缺失**：DTO 转换 / 字段白名单 / 显式 setter

### 3.2 AST 模式
```yaml
pattern: $REPO.save($REQUEST_BODY_ENTITY)
# 配合：实体类含敏感字段
```

### 3.3 SQLite 特征
```sql
SELECT m.fqn FROM method m
WHERE m.body LIKE '%@RequestBody%'
  AND (m.body LIKE '%save%' OR m.body LIKE '%update%')
  AND m.body NOT LIKE '%toEntity%'
  AND m.body NOT LIKE '%setRole%'  -- 显式赋值
```

## 四、缺失规则

| 实体 | 敏感字段（不应被请求体覆盖） |
|------|------------------------------|
| User | role, isAdmin, balance, status, password（应单独接口） |
| Order | status, paidAt, totalAmount |
| Product | price（应服务端算） |

## 五、消毒器

| 消毒器 | 检测特征 |
|--------|---------|
| **DTO 转换** | 显式 `UserDTO → UserEntity` 映射 |
| **白名单字段** | Spring `@JsonView` 或显式 setter |
| **单独字段 setter** | 只 set 安全字段，不直接 save |
| **`@PreAuthorize` 保护敏感 setter** | 敏感字段单独路径 + 鉴权 |
