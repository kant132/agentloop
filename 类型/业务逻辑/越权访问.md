# 越权访问

> **类型 ID**: `AP-BIZ-ACCESS`
> **轨道**: FWD-C
> **业务域**: 9 类必查之一

## 一、定义

低权限用户访问了高权限功能。分为：
- **垂直越权**：普通用户访问 admin 功能
- **水平越权**：用户 A 访问用户 B 的资源（见 IDOR）
- **上下文越权**：普通用户调管理 API 但 role 由客户端控制

## 二、典型场景

### 2.1 垂直越权
```java
// ❌ admin 接口无 @PreAuthorize
@PostMapping("/admin/users")
public User createUser(@RequestBody User user) {
    return userService.save(user);
}
```

### 2.2 客户端传 role
```java
// ❌ role 来自请求体
@PostMapping("/register")
public User register(@RequestBody User user) {
    user.setRole(user.getRole());  // 直接用请求里的 role
    return userService.save(user);
}
```

### 2.3 隐藏接口
```java
// ❌ 通过 URL 直接访问
@GetMapping("/internal/debug")
public Map<String, Object> debug() {
    return systemInfo;  // 内部接口但无鉴权
}
```

## 三、检测启发式

### 3.1 AST 模式
```yaml
# 缺 PreAuthorize 的 Controller 方法
pattern: |
  $$$ANNOTATIONS
  public $$$RET $METHOD($$$PARAMS) {
    $$$BODY
  }
# 配合：路径含 /admin/ 或 @PreAuthorize 缺
```

### 3.2 SQLite 特征
```sql
-- 找含 admin 路径但无 @PreAuthorize
SELECT m.fqn, m.class, m.file, m.line
FROM method m
JOIN class cls ON cls.fqn = m.class
WHERE m.body LIKE '%/admin/%'
  AND m.annotation NOT LIKE '%PreAuthorize%'
  AND m.annotation NOT LIKE '%Secured%'
```

## 四、缺失规则

| 端点类型 | 必需鉴权 |
|----------|---------|
| `/admin/**` | admin 角色 |
| `/internal/**` | 内网 IP + admin 角色 |
| `/api/**` 增删改 | 登录用户 + 对象归属 |
| `/api/**` 读 | 登录用户 + 对象归属（如有隐私） |

## 五、误报模式

- 已有全局 Filter 覆盖
- 路径含 `/public/` 或 `permitAll`
- 内部网络 IP 限制（但需结合环境信息判定）
- 单点登录已通过 SSO 校验
