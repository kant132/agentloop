# 路径遍历

> **类型 ID**: `AP-FILE-PATH-TRAVERSAL`
> **轨道**: FWD-A + FWD-C
> **业务域**: 9 类必查之一（文件操作类）

## 一、定义

用户输入拼接到文件路径，攻击者通过 `../` 读取/写入任意文件。

## 二、典型场景

```java
// ❌ 路径未规范化
@GetMapping("/files")
public Resource getFile(@RequestParam String name) throws IOException {
    return new FileSystemResource("/data/" + name);  // name=../../etc/passwd
}
```

## 三、检测启发式

### 3.1 AST 模式
```yaml
pattern: new File($BASE + $VAR)
pattern: new FileInputStream($PATH + $VAR)
pattern: Files.newInputStream(Paths.get($PATH + $VAR))
```

### 3.2 SQLite 特征
```sql
SELECT m.fqn FROM method m
WHERE m.body LIKE '%new File(%'
   OR m.body LIKE '%new FileInputStream(%'
   AND m.body NOT LIKE '%FilenameUtils.getName%'  -- 缺失：路径规范化
```

## 四、消毒器

| 消毒器 | 检测特征 |
|--------|---------|
| **`FilenameUtils.getName`** | 取文件名，去掉路径 |
| **`Path.normalize`** | 规范化，去掉 `..` |
| **白名单前缀** | `if (!path.startsWith("/data/")) throw` |
| **白名单字符** | `Pattern.matches("[a-zA-Z0-9_.-]+", name)` |
