# 任意文件上传

> **类型 ID**: `AP-FILE-UPLOAD`
> **轨道**: FWD-C
> **业务域**: 9 类必查之一

## 一、定义

文件上传未校验类型/扩展名/内容，攻击者可上传 webshell 接管服务器。

## 二、典型场景

```java
// ❌ 不校验类型
@PostMapping("/upload")
public String upload(@RequestParam MultipartFile file) throws IOException {
    String dest = "/data/" + file.getOriginalFilename();  // 原始文件名
    file.transferTo(new File(dest));  // .jsp / .php / .exe 都接受
    return "ok";
}
```

## 三、检测启发式

### 3.1 关键信号
- `MultipartFile.transferTo(...)`
- `getOriginalFilename()` 用作保存路径
- **缺失**：扩展名校验 / MIME 校验 / 内容校验

### 3.2 SQLite 特征
```sql
SELECT m.fqn FROM method m
WHERE m.body LIKE '%MultipartFile%'
  AND m.body LIKE '%transferTo%'
  AND m.body NOT LIKE '%endsWith%'  -- 缺扩展名校验
  AND m.body NOT LIKE '%MimeType%'
```

## 四、缺失规则

| 文件类型 | 必需校验 |
|----------|---------|
| 图片 | 扩展名 + MIME + 魔数 |
| 文档 | 扩展名 + MIME |
| 任意 | 禁止 .jsp / .php / .exe |

## 五、消毒器

| 消毒器 | 检测特征 |
|--------|---------|
| **扩展名白名单** | `if (!ALLOWED_EXT.contains(ext)) throw` |
| **MIME 校验** | `file.getContentType()` 检查 |
| **魔数校验** | 读取文件头几字节 |
| **重命名** | `UUID.randomUUID() + ext` |
| **存储目录分离** | 不可执行目录 |
