# 模板注入（SSTI / RCE）

> **类型 ID**: `AP-INJ-TEMPLATE`
> **轨道**: FWD-A
> **业务域**: 9 类必查之一

## 一、定义

用户输入被拼接到模板引擎的字符串中执行。攻击者可执行任意模板表达式（如 Freemarker OGNL、Thymeleaf SpEL、Velocity）。

## 二、典型场景

### 2.1 Freemarker
```java
// ❌ 危险
String template = "Hello, " + userInput;
String result = new Template("name", new StringReader(template), cfg).process(...);
```

### 2.2 Velocity
```java
// ❌ 危险
Velocity.evaluate(ctx, writer, "name", "Hello, " + userInput);
```

### 2.3 Thymeleaf / SpEL
```java
// ❌ 危险
String expression = "T(java.lang.Runtime).getRuntime().exec('" + cmd + "')";
SpelExpressionParser parser = new SpelExpressionParser();
Expression exp = parser.parseExpression(expression);
```

## 三、检测启发式

```yaml
pattern: new Template($NAME, $READER, $CFG).process(...)
pattern: Velocity.evaluate($CTX, $W, $N, $TPL + $VAR)
pattern: parser.parseExpression($EXPR + $VAR)
```

## 四、消毒器

| 消毒器 | 检测特征 |
|--------|---------|
| **Freemarker 沙箱** | `Configuration.setNewBuiltinClassResolver(CLASS_ALLOWLIST_RESOLVER)` |
| **Velocity 沙箱** | `VelocityEngine.setProperty("runtime.introspector.uberspect", SecureUberspector.class.getName())` |
| **Thymeleaf 表达式前缀限制** | 仅 `${...}` 不含 `__${...}__` |
| **SpEL 白名单** | 不允许 `T(java.lang.Runtime)` |

## 五、误报模式

- 模板字符串完全硬编码
- 用户输入仅作为变量值传入 `model`，未拼接到模板字符串

## 六、业务影响

**最高** — 模板执行等于代码执行 = RCE
