## 五、Memurai 缓存特殊配置

> 审计侧使用 `memurai-cli` 写入；项目本身的 Redis 缓存若与审计 key 共用 Memurai 实例，
> 必须设置业务前缀以避免审计 `:method:*` / `:finding:*` key 与业务 key 冲突。

### 5.1 缓存 key 前缀
- 业务缓存用什么前缀？避免与审计 key `audit:{groupId}:commit:*` 冲突
- 审计 key 已自带 `audit:` 前缀 + groupId 隔离，建议业务侧也走 `biz:` 前缀

### 5.2 memurai-cli 共用
- 审计脚本默认连接 `localhost:6379`；若业务 Memurai 在不同端口，加 `--redis-port`
- 多实例共存：业务 Memurai 走 `6380`，审计 Memurai 走 `6379`
