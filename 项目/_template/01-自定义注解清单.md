# 自定义注解清单

> 项目使用的自定义注解，及每个注解的语义。FWD-B / FWD-C 启动时必读。

## 一、注解清单

按以下格式登记每条项目特有注解：

```markdown
### {注解全限定名}
- **用途**：{说明}
- **适用位置**：{类/方法/字段/参数}
- **对 FWD-B 的影响**：
  - 视为鉴权？→ 是 / 否 / 部分
  - 等价于哪个标准注解？→ @PreAuthorize / @Secured / ...
- **示例代码**：
  ```java
  @MyAuth
  public void doSomething() { ... }
  ```
- **首次发现**：{date}
- **sha256**：{hash}
```

## 二、登记样例

### @Inner
- **用途**：标记内部接口（仅内网访问）
- **适用位置**：方法
- **对 FWD-B 的影响**：视为鉴权（限内网）
- **示例代码**：
  ```java
  @Inner
  @GetMapping("/api/internal/status")
  public Status getStatus() { ... }
  ```
- **首次发现**：2026-06-12
- **sha256**：a1b2c3d4e5f6

### @OpenApi
- **用途**：标记对 OpenAPI 网关暴露的接口
- **适用位置**：方法
- **对 FWD-B 的影响**：视为鉴权（网关层）
- **示例代码**：
  ```java
  @OpenApi
  @PostMapping("/api/open/create")
  public Result create(@RequestBody Foo foo) { ... }
  ```
- **首次发现**：2026-06-12
- **sha256**：f6e5d4c3b2a1

## 四、检测启发式

- 全项目搜索 `import` 包含 `com.{yourgroup}.annotation`
- 找到所有 `@Xxx` 形式注解
- 对每个 Xxx，查代码中 `@Xxx` 出现位置
- 按上述模板登记
