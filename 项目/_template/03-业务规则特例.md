# 业务规则特例

> 项目特有的业务校验逻辑，**豁免**于通用业务规则模板。FWD-C 启动时必读，避免假阳。

## 一、特例登记

按以下格式登记每条业务规则特例：

```markdown
### {业务对象}
- **通用规则**：{在 类型/业务逻辑/{X}.md 中描述的规则}
- **项目特例**：{项目实际如何处理}
- **是否豁免**：{是 → 不报 / 否 → 仍要报}
- **豁免理由**：{...}
- **首次发现**：{date}
- **sha256**：{hash}
```

## 二、登记样例

### Order
- **通用规则**：订单查询应校验当前用户 = 订单 userId（IDOR）
- **项目特例**：内部运营查询接口（`/api/internal/orders/{id}`）允许运营人员查任意订单
- **是否豁免**：部分豁免（仅 `/api/internal/orders` 豁免）
- **豁免理由**：运营业务需要
- **首次发现**：2026-06-12
- **sha256**：b2c3d4e5f6a1

### User
- **通用规则**：用户注册时 role 应默认为 USER，不接受请求体
- **项目特例**：项目用 `@AllowAdmin` 注解标记白名单接口，role 可为 ADMIN
- **是否豁免**：部分豁免（带 `@AllowAdmin` 的接口豁免）
- **豁免理由**：开放接口
- **首次发现**：2026-06-12
- **sha256**：c3d4e5f6a1b2
