# 已知误报模式

> 项目里**像漏洞但不是漏洞**的代码模式。FWD-X 命中时必查。

## 一、误报模式登记

按以下格式登记每条误报模式：

```markdown
### {模式名}
- **触发**：{FWD-X 命中时的具体信号}
- **实际状态**：{SANITIZED / SAFE / N/A}
- **正确做法**：{如何确认是误报}
```

## 二、登记样例

### MyBatisProvider 拼接
- **触发**：FWD-A 命中 `Provider.method() returns String` 含 `${}`
- **实际状态**：SAFE
- **正确做法**：检查 Provider 内部是否仍用 `${}` 还是 `#{}`，若是 `${}` 仍报

### 自定义 Interceptor 全局兜底
- **触发**：FWD-B 发现某 Controller 无 `@PreAuthorize`
- **实际状态**：SANITIZED（被全局 Interceptor 兜底）
- **正确做法**：检查是否有 `LoginRequiredInterceptor` 等全局兜底
