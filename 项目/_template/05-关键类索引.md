# 关键类索引

> 项目中**高价值审计目标**的类清单。FWD 启动时优先分析。

## 一、必查类（高危业务域）

按以下格式登记每类：

```markdown
### {业务对象}
- **对应类**：
  - Controller: {fqn}
  - Service: {fqn}
  - DAO: {fqn}
- **风险点**：{该对象常见漏洞}
- **优先级**：P0 / P1 / P2
```

## 二、登记样例

### 用户认证
- **对应类**：
  - Controller: `com.example.UserController`
  - Service: `com.example.UserService`
  - DAO: `com.example.UserDao`
- **风险点**：登录绕过、密码泄露、session 固定
- **优先级**：P0

### 订单
- **对应类**：
  - Controller: `com.example.OrderController`
  - Service: `com.example.OrderService`
  - DAO: `com.example.OrderDao`
- **风险点**：IDOR、状态机绕过、支付绕过
- **优先级**：P0

### 文件上传
- **对应类**：
  - Controller: `com.example.UploadController`
  - Service: `com.example.UploadService`
- **风险点**：任意文件上传、路径遍历
- **优先级**：P0
