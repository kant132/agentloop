### 常见坑
- SQL注入：ORM动态查询（MyBatis ${}）≠ 参数化；二阶注入；ORDER BY/LIMIT 无法参数化
- 命令注入：分隔符 ; && || ` $()；空格绕过 $IFS
- XXE：默认不禁用 external entities；嵌套 XML 内层 parser 未保护
- 反序列化：JSON（fastjson）@type/@class 可加载任意类
- 表达式注入（SpEL/OGNL）：注解中用户可控数据、标签属性中表达式求值
- 禁止行为：假设框架自动防御；只看过滤逻辑不看调用链上下文；忽略二阶注入；写修复建议

    var headers = parse(header);
    var payload = parse(payloadAsString);

    var builder =
        JWTToken.builder()	//fqn: JWTToken.builder
            .header(write(header, headers))
            .payload(write(payloadAsString, payload))

            .validToken(true)
            .validPayload(!hasText(payloadAsString) || !payload.isEmpty());	//fqn: java.util.Map.isEmpty

    JsonWebSignature jws = new JsonWebSignature();
    jws.setPayload(payloadAsString);	//fqn: jws.setPayload
    headers.forEach((k, v) -> jws.setHeader(k, v));	//fqn: java.util.Map.forEach
    if (!headers.isEmpty()) { // otherwise e30 meaning {} will be shown as header	//fqn: java.util.Map.isEmpty
