# 必读 06：三哲学自检模板

> **目的**：每轮反思必含马斯克（第一性原理）、康德（批判哲学）、苏格拉底（诘问法）三视角，作为反思评分 30 分项的子项。

## 一、马斯克（第一性原理）

> 拆解到最基本事实，从零开始重建推理。

**模板问题**（3 选 1 或自定义）：

1. 这个步骤的本质目的是什么？是否还成立？
2. 有没有更短的路径达到同样目的？
3. 如果去掉所有"业内惯例"，最朴素的攻击者会怎么找这个漏洞？

**输出格式**：
```markdown
### 马斯克视角
- 拆解：{最基本事实}
- 重建：{最朴素路径}
- 改进：{如果存在更短路径}
```

## 二、康德（批判哲学）

> 检验先验假设、普遍性、是否可证伪。

**模板问题**（3 选 1）：

1. 这个判断的先验假设是什么？哪些假设未经验证？
2. 这个规则在所有项目中都成立吗？反例是什么？
3. 如果有 10 个反例同时反对，我应该立刻推翻这个规则吗？

**输出格式**：
```markdown
### 康德视角
- 假设：{显式假设 + 隐式假设}
- 普遍性：{在哪些情况下失效}
- 可证伪性：{能否被 X 推翻}
```

## 三、苏格拉底（诘问法）

> 持续追问，反方最强的反驳是什么。

**模板问题**（3 选 1）：

1. 如果反方说"这个漏洞不存在"，最强反驳是什么？
2. 这个判定漏掉了什么前提条件？
3. 攻击者真正利用这个漏洞的最短路径是什么？我假设的 PoC 是不是过度设计？

**输出格式**：
```markdown
### 苏格拉底视角
- 反方最强反驳：{最强的反方观点}
- 我的回应：{为什么仍判定为漏洞}
- 攻击者最短路径：{最可能真实发生的利用方式}
```

## 四、自检输出位置

每轮反思的产出物 `loop_audit/反思报告-round{N}.md` 必须包含这三段，**不可省略**。

## 五、评分挂钩

- 三段都齐全且有实质内容 → 30 分项满分
- 缺 1 段 → -10 分
- 有形式无内容（只写"已自检"） → -5 分
- 有反方反驳但无回应 → -8 分

## 六、调用时机

- 反思 subagent 启动时 → 强制加载本文
- 每轮 Loop 结束 → 必输出三段
- 评分 subagent 看到三段 → 启用挂钩评分

## 七、错误示例 ❌

```markdown
### 马斯克视角
- 已自检，符合第一性原理。
```

（无内容，仅占位）

## 八、正确示例 ✅

```markdown
### 马斯克视角
- 拆解：FWD-A 的本质是"从端点出发，沿调用链找危险 Sink"
- 重建：朴素做法 = 全文 grep 危险函数 → 列调用栈
- 改进：朴素做法慢、漏；当前做法 = codegraph SQL 一次查链 + ast-grep 验 sink，更快更全
- 结论：当前做法已接近最优，无明显更短路径
```
